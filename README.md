# 冥想时代

一款微信小程序冥想打卡应用，界面为中国风水墨画风格（宣纸底、淡墨远山、云雾飘动、朱砂印章、楷体字）。

## 功能

- **开始冥想**：支持预设时长倒计时（1/5/10/15/20 分钟）与自由计时两种模式，冥想中呈现「圆相」墨圈呼吸动画
- **冥想打卡**：冥想结束自动记录打卡时间与时长（满 1 分钟才计入），累加到总冥想时间，完成时「盖章」确认，并可在结束弹层补写一段文字感想（亦可直接保存不留文字）
- **冥想等级**：按累计时长划分 8 级 —— 初心 → 静心(50h) → 安心(200h) → 定心(500h) → 观心(1200h) → 明心(2500h) → 慧心(5000h) → 圆满(10000h)
- **时间轴**：历史打卡以时间轴呈现，每次打卡为一个节点 —— 普通节点 / 留字节点（写有文字感想）/ 里程碑节点（冥想等级晋级的时刻，朱砂印章标记）；支持「仅留字」筛选与按年月快速定位
- **动态水墨背景**：`components/ink-bg` 组件，含三重远山、云雾漂移、墨点上浮动效

## 数据存储

采用「本地缓存 + 云端同步」双源策略（统一封装在 `miniprogram/utils/storage.js`）：

- **本地缓存为即时权威**：读写入瞬时完成，打卡、等级统计、冥想会话恢复等关键路径不依赖网络
- **云端（微信云开发）为跨设备备份**：本地写入后进入待同步队列异步上云，失败自动留队重试、按记录 id 幂等去重（断网打卡不丢、恢复联网自动补传不重复）；页面 onShow 时拉取云端合并刷新
- **冥想会话（进行中的冥想）保持纯本地**：重启恢复不依赖网络
- **云环境未配置或不可用时自动退化为纯本地模式**，功能完整不受影响

### 云端部署（一次性）

1. 微信开发者工具 → 顶部「云开发」→ 开通并创建环境（如 `meditation-prod`）
2. 云开发控制台 → 数据库 → 创建集合 `records` → 权限设为**「仅创建者可读写」**
   （数据按微信 openid 自动隔离：用户无需登录，他人无法读写你的打卡数据）
3. 把环境 ID 填入 `miniprogram/envList.js`：`[{ envId: "你的环境ID", alias: "冥想" }]`
   （开发者工具在选择环境后也会自动写入该文件）
4. 重新编译运行：本地历史记录会在首次同步时自动上传（仅提示一次「已与云端同步」）；
   同微信号换设备打开小程序，自动拉取同一份数据

> 代码在环境未配置时保持纯本地运行，随时可补齐上述步骤启用云端。

## 目录结构

```
miniprogram/
├── app.js               # 小程序入口（初始化云开发：有环境配置则启用云端同步）
├── app.json             # 全局配置（页面注册、导航栏）
├── envList.js           # 云开发环境 ID 列表（工具维护，空数组 = 纯本地模式）
├── components/
│   └── ink-bg/          # 水墨动态背景组件（远山、云雾、墨点）
├── utils/
│   ├── env.js           # 云环境 ID 读取（envList 的唯一消费入口）
│   ├── levels.js        # 冥想等级体系与时长格式化
│   └── storage.js       # 数据抽象层（本地缓存 + 云端同步双源）
├── pages/
│   ├── index/           # 冥想主页（开始冥想、计时、打卡、等级展示）
│   └── records/         # 时间轴页（历史记录与统计）
```
